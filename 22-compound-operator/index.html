Compound Operators in JavaScript

Common Compound Operators in JavaScript

Operator Example Equivalent To
+= x += y; x = x + y;
-= x -= y; x = x - y;
*= x *= y; x = x * y;
/= x /= y; x = x / y;
%= x %= y; x = x % y;
**= x **= y; x = x ** y;
<<= x <<= y; x = x << y;
>= x >>= y; x = x >> y;
>>= x >>>= y; x = x >>> y;
&= x &= y; x = x & y;
|= x |= y; x = x | y;
^= x ^= y; x = x ^ y;
